About the Project

A final year engineering project that combines embedded systems, cloud infrastructure, and a real-time web dashboard to detect and map buried electrical cables non-invasively.

Hardware

  • MicrocontrollerESP32-S3
  • Sensor3-Axis Magnetometer
  • GPS ModuleNEO-6M / NEO-8M
  • ConnectivityWi-Fi 802.11 b/g/n
  • Power3.3V / USB-C
  • Update RateEvery 5 seconds

How It Works

  • 1. ScanMagnetometer reads field
  • 2. ClassifyESP32 computes signal %
  • 3. StampGPS coordinates attached
  • 4. UploadPOST to Supabase via HTTPS
  • 5. PushRealtime to dashboard
  • 6. ControlDashboard sends ON/OFF
